# Auditing biological foundation models

Three studies asking one question, five different ways:

> **How do you know a biological foundation model is measuring biology and not the
> instrument?**

Every experiment here is an instance of it, and the answer is consistently that
the model measures the instrument a great deal — and that **you cannot see this
from the loss curve**.

| study | question actually asked | answer |
|---|---|---|
| protein multimodal FM | does the structure token encode structure? | **0.55 of 2.39 bits** of SS8 entropy (23%), while the loss looked perfect |
| BreaKHis | malignancy, or *this patient's slide*? | patient identity decodable at **96.9%** |
| CAMELYON17 | metastasis, or *this hospital's scanner*? | hospital decodable at **99.77%** (chance 29.9%) |
| morphology ↔ transcriptome | does morphology inform, or is spatial smoothing enough? | morphology **0.005** CRPS vs spatial **0.05** |
| clinical grading | lesion size, or the classifier's own threshold? | fitted cut points span **0.213–0.453 mm** across hospitals |

Everything was measured on one laptop (Apple M4 Max, MPS) from public data.
No number is estimated.

### Why a verification harness exists at all

Each individual experiment in this repository was run against whatever data
existed when it was written — 38 slides, then 41, then 50, then 56, then 65. Every
analysis was individually defensible and **none of them were comparable to each
other**. That is a defect in the study, not in any one experiment.

`verify.py` fixes it with four mechanisms:

| mechanism | prevents |
|---|---|
| dataset frozen by content hash | quoting numbers computed on different data as if comparable |
| claims + nulls **pre-registered before computing** | "beat zero" masquerading as a result |
| tiers: `RESOLVED` / `NULL` / `UNDERPOWERED` | underpowered noise becoming a finding |
| one seed policy (0–4) everywhere | per-analysis choices tuned after the fact |

## The three findings that survive

**1. Site robustness is a property of the representation, not of the task.**
`delta_site` is a genuine null — +0.0077 with 2·SE 0.0136, below the 0.02 effect
size pre-registered as mattering, with matched test sets on all five folds. But on
the *same* task:

| | across-hospital AUC SD | worst hospital |
|---|---|---|
| raw-pixel (colour histogram) | 0.2252 | **0.3750** — below chance |
| Phikon (ViT-B, iBOT on TCGA) | **0.0284** | 0.9117 |

raw-pixel *anti-predicts* on one held-out hospital: the colour feature separating
tumour in four hospitals reverses in the fifth. Reporting only a mean misses this
entirely. A deployment decision depends on the worst hospital.

**2. Leakage is real and encoder-dependent.** Moving from a random tile split to a
patient-disjoint one costs raw-pixel **+0.1179** AUC and Phikon **+0.0199**. A weak
encoder leans on slide-specific colour, so it leaks far more.

**3. Best biology and heaviest confound live in the same model.** Phikon has the
best tumour AUC *and* identifies the hospital at 99.77%. The identical coupling
appears on BreaKHis with patient identity (96.9%) — **reproduced across two
datasets with two different confound variables.**

## Loss does not predict representation quality — in either direction

| run | loss / dynamics | representation |
|---|---|---|
| protein VQ tokenizer | loss 3.69→1.78, codebook 512/512 used, perplexity 444 — **perfect** | **useless**: 0.55 of 2.39 bits |
| DINO, 4096 prototypes | loss flat 7.03→6.86, teacher drifting to uniform — **bad** | **usable**: 0.837 AUC |
| DINO, 256 prototypes | loss falls 5.05→3.95, teacher structures — **healthy** | **no better**: 0.848, within noise |

Purpose-built collapse diagnostics (`teacher_entropy`, `kl_uniform`,
`top1_share`) correctly described the dynamics every time and predicted downstream
quality **never**. Only parameter-free probes on frozen features did.

## Twelve defects caught, and what each would have produced

None of these raise an error. Every loss curve stayed normal. Each one produces a
publishable-looking number.

| defect | what it silently produces |
|---|---|
| geometric attention fed true coordinates | `sequence → structure` eval reads the answer off its input |
| `masks/*.tif` used as tumour masks — they are **tissue** masks | **100% of tiles positive**, AUC ≈ 1.0, looks like a triumph |
| `pos_thr=0.5` on lesion coverage | 16 of 50 slides contribute **zero** signal, ITC stratum silently deleted |
| auditing XML structure with `grep` | a phantom annotation class that is really a `<Group>` header row |
| null hypothesis set to zero | **random features** declared effective |
| comparing across training budgets | concluded "my fix is harmful" — the **opposite** of the truth |
| feature cache keyed without patch size | 96 µm features silently reused for a 138 µm experiment |
| `delta_site` v1/v2/v3 | three clean-looking numbers, each confounded by a different nuisance (grade, test size, train size) |
| no mid-run checkpointing | 5,750 of 6,000 steps discarded on a wall-clock kill |
| extrapolating rate from a differently-configured smoke test | 25-minute estimate for a 37-minute run |
| **SD used where SE belonged** | a real +0.185 effect reported as underpowered |
| **unpaired comparison of paired measurements** | 2·SE inflated 0.090 → 0.317, burying that effect |

The last two were caught by the harness **on its author**.

### Four numbers I published and then had to correct

| quantity | I claimed | verified | cause |
|---|---|---|---|
| value of segmentation | 0.64 κ | **+0.3133** | differenced two κ computed over **different slide populations** |
| `delta_site` | −0.028, underpowered | **+0.0077, NULL** | matched test sets, equalised training, all 65 slides |
| Phikon leak | +0.072 | **+0.0199** | negative slides not yet downloaded |
| raw-pixel leak | +0.263 | **+0.1179** | different slide set |

The 0.64 was the worst: two kappas over different populations, differenced and
presented as an effect size. Precisely what the harness exists to prevent.

### Three hypotheses of mine that the experiments killed

- Stain augmentation would trade confound for biology → **both halves false**.
  Biology rose monotonically (+0.0475); confound stayed flat within error bars.
- The ITC grading failure was a stride/resolution problem → **finer stride made it
  worse**. Calibration merely traded ITC errors for micro errors (κ 0.308→0.332).
- The structure tokenizer's weakness was a decoder-head problem → **distogram MDS
  reconstruction was worse** (12.48 Å vs 11.98 Å); the tokens themselves were thin.

The ITC falsification was the most useful: it converted "did not implement
segmentation" into "**measured that segmentation is worth +0.3133 κ**".

## Repository layout

```

  data.py                      RCSB 30%-identity clusters -> DSSP SS8 + Shrake-Rupley SASA
  struct_tokenizer.py          geometric encoder + EMA VQ + FAPE/distogram decoder
  multimodal.py                shared trunk, per-track noise schedule, any-to-all eval
  diag_local.py                parameter-free token information probe (the key tool)
  decode.py                    SS8 prompt -> co-generate -> decode 3D -> re-run DSSP

pathology-fm/src/
  verify.py                    SINGLE SOURCE OF TRUTH: frozen snapshot, pre-registered
                               claims, paired SEs, RESOLVED/NULL/UNDERPOWERED tiers
  pathdata.py                  3 split regimes, Macenko normalisation
  backbone.py                  ViT + HED stain jitter + full dihedral augmentation
  dino.py                      DINO SSL with collapse monitoring as a first-class metric
  audit.py                     linear probe + confound probes, rank-based AUC, no sklearn
  mil.py                       gated-attention MIL over patient bags
  wsi.py                       tissue detection + lesion-guided tiling from ASAP XML
  c17data.py                   random / slide / patient / centre split regimes
  c17site.py                   paired leave-one-centre-out with matched test sets
  c17stage.py                  AJCC size rule -> slide grade -> pN, two-stage validation
  xmodal.py                    morphology <-> transcriptome, MSE vs rectified flow, CRPS
  frontier.py                  stain-jitter sweep with across-seed error bars

```

## Data (not included — 185 GB)

All public, all fetched by scripts in the repo:

| dataset | size | fetched by |
|---|---|---|
| BreaKHis v1 — 7,909 images, 81 patients | 4 GB | `get_breakhis.py` |
| CAMELYON17 — 65 whole slides, 5 hospitals | 180 GB | `get_camelyon17.py` |
| 10x Visium Human Lymph Node — 4,035 spots | 425 MB | `get_hest.py` |
| RCSB PDB — 5,770 proteins, 857k residues | ~1 GB | `protein-multimodal-fm/src/data.py` |

`get_camelyon17.py` is resumable and size-verifying, and downloads
centre-interleaved so leave-one-hospital-out becomes runnable at ~40% of the
transfer rather than 100%. Measured throughput was link-saturated at 17 MB/s —
eight concurrent streams gave the same aggregate as one.

HEST-1k was the intended spatial-transcriptomics source but is gated (HTTP 403
even authenticated), so an open 10x Visium sample was substituted. The
coordinate-to-pixel mapping was verified with an axis-swap control: 0/200
mismatches correct, 50/50 when deliberately swapped.

## Limitations, stated plainly

- **Cross-modal results are n=1 slide, one tissue** (lymph node). Not generalisable.
- **pN staging is not scoreable here.** It needs all five nodes per patient; only
  the lesion-annotated subset was downloaded (nodes-per-patient `{1: 37, 2: 5, 3: 1}`).
  The official rule is implemented and runs, reported as a pipeline demonstration.
- **Segmentation is not implemented.** Its value is measured (+0.3133 κ), not delivered.
- **No IHC.** H&E only.
- The DINO encoder saw 5,354 patches from 55 patients for 2,500 steps. It is not
  comparable in scale to Phikon and is not presented as such.
- Flow model `cov90 = 0.817` against a 0.90 target — mildly overconfident, wants
  post-hoc calibration.
